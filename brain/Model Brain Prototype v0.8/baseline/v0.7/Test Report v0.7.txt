Invalid early evidence:

The first apparent PASS used two scripted conveniences: a fixed-text Person fallback and a direct ID for the incomplete event. They were removed. The non-scripted run initially failed, revealing unreliable 2B intent classification and failure of a flat mixed-node top-12 to retain the correct Person. The final PASS used a better local 4B intent classifier, type-bounded candidate regions, similarity thresholds and deterministic Source / Relation traversal.

Known limitation

The v0.7 test loaded the full 193-node Candidate Index before semantic ranking. Working Set size therefore grew with the index, so this design was not suitable for unbounded growth.

Next correction:

- Hierarchical Region Index.
- Semantic ranking only inside the selected Person or Event shard.
- Once a seed node is chosen, traverse exact Relation / Source edges through deterministic node addressing.
- Do not load the global node index into cognition.
- Repeat wrong-source, stale, incomplete and UNKNOWN gates.
