Failure and repair record

The first orchestrated run reported FAIL even though all four task evidence blocks were correct. Cause: the verifier expected Unix-style line endings when counting GLOBAL_CATALOG_LOADED=False. Windows CRLF prevented the exact end-of-line regular expression from matching. The repair changed only evidence counting; Oracle, expected answers, retrieval thresholds, and task data were not relaxed. All three seeds were then rerun.
